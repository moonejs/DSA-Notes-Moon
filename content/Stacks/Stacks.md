- Stack of chocolates

You keep one chocolate on top of another.

Now tell me 
If you want to eat one chocolate, which one will you take?

 The **top one**, right?

You can’t pull the chocolate from the bottom 
Everything happens from the **TOP only**.


Stack follows one simple rule:

>  **Last In, First Out (LIFO)**

### Stack Operations 

##### 1. Push = Put something on top

Like putting one more chocolate on stack.

#####  2. Pop = Remove from top

Like eating the top chocolate 

##### 3️. Peek = Just look at top

Like checking which chocolate is on top without eating it.


>[!note]
>A Stack is a non-primitive linear data structure. It is an ordered list in which the addition of a new data item and deletion of an already existing data item can be done from only one end, known as `top` of the stack.

The last added element will be the first to be removed from the Stack. That is the reason why stack is also called **Last In First Out (LIFO)** type of data structure.
