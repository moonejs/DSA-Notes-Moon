
>**Time Complexity** = how long algorithm runs.

>**Space Complexity** = how much extra memory the algorithm uses.

Not the input memory.

Extra memory.

When a program runs, it needs:

1. Input storage (already given)
    
2. Extra variables
    
3. New arrays (if created)
    
4. Recursion stack memory
    

Space complexity measures:

How much additional space grows with input size.

If algorithm uses:

- No extra list
    
- No recursion
    
- Only fixed number of variables
    

It is called:

👉 **In-place algorithm**

Selection sort is in-place.
